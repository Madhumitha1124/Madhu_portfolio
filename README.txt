Madhumitha S. — Portfolio
=========================
Open index.html in any modern browser (internet needed for fonts and libraries).

To edit your content, open index.html in a text editor and find the block
"EDIT YOUR CONTENT HERE" near the top of the script. You can change:
  EMAIL, LINKEDIN, GITHUB, RESUME  - links (leave "" to hide an item)
  projects     - title, description, tags, link (GitHub repo) and img (screenshot URL)
  skills, leadership, certs - lists shown on the page

To publish: upload index.html to any static host (GitHub Pages, Netlify, Vercel).
